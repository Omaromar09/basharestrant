# دجاج بندق | Bondok Chicken

الموقع الإلكتروني الرسمي والمتكامل لمطعم دجاج بندق (Bondok Chicken) - مستخرج بالكامل من قائمة طعام إلمنيوز الرسمية، بتجربة مستخدم سريعة وخالية تماماً من أي إيموجي.

---

## أبرز مميزات الموقع:

1. **المنيو الكامل والشامل (78 صنفاً من إلمنيوز)**:
   - الساندوتشات (فردي ودبل وتريبل وكومبو)
   - ساندوتشات رول وتويستر
   - وجبات دجاج مقرمشة (قطع عادية وعائلية)
   - وجبات تندر واستربس
   - وجبات عائلية وبوكسات اللمة
   - أطباق ريزو بصوصات بندق
   - وجبات الأطفال
   - الأصناف الجانبية (بطاطس، كول سلو، أرز، حلقات بصل، هالبينو شيدر)
   - المشروبات الغازية والعصائر

2. **نظام طلب دليفري ذكي (Delivery)**:
   - تحديد العنوان والمناطق بدقة.
   - احتساب وقت الوصول التقديري والتوصيل المجاني للطلبات الكبيرة.

3. **نظام الاستلام المسبق من الفرع (Pickup) بدون انتظار**:
   - حجز الطلب أونلاين والاستلام فور الوصول بكود الطلب بدون الوقوف في أي طابور.
   - فروع المعادي، مدينة نصر، التجمع الخامس، والمهندسين.

4. **تخصيص كامل للوجبات (Customizer Modal)**:
   - اختيار الحجم (ساندوتش / كومبو / وجبة / قطع).
   - اختيار المشروب (بيبسي، سفن اب، ميرندا).
   - اختيار درجة الحرارة (عادي مقرمش / سبايسي حار).
   - إضافات وصوصات (شيدر، تركي مدخن، هالبينو، روزبيف، حلقات بصل).

5. **سلة مشتريات تفاعلية وكوبونات خصم**:
   - كود خصم: `BONDOK20` (خصم 20%) أو `CRUNCHY` (خصم 15%).

6. **إتمام الطلب وتكامل واتساب**:
   - الدفع كاش أو إنستاباي / محافظ إلكترونية.
   - إرسال تفاصيل الفاتورة كاملة ومجهزة إلى واتساب المطعم مباشرة.

7. **تتبع مباشر لحالة الطلب (Live Order Tracking)**:
   - مراحل التجهيز والتوصيل خطوة بخطوة.
   - إمكانية طباعة الفاتورة.

8. **تصميم احترافي متجاوب خالي من الإيموجي**:
   - أيقونات SVG عصرية وأنيقة بدلاً من الإيموجي في كامل أجزاء الموقع.

---

## طريقة التشغيل:

- فتح ملف `index.html` مباشرة في أي متصفح ويب.
- أو عبر Node.js:
```bash
npm start
```
أو:
```bash
node server.js
```
الرابط المحلي: `http://localhost:3000`
